# Andrew Lucas | Baseball Analytics Portfolio

A collection of my baseball analytics projects exploring player
performance, pitch quality, swing decisions, matchup modeling,
and hitter skill forecasting.

## Projects

- **P4 Swing Decision Report:** Analysis of college hitters’ swing decisions.
- **Bryan Rincon’s 2026 Breakout:** Player performance analysis.
- **Paul Skenes Pitch Quality and Effectiveness:** Pitch-level analysis.
- **P4 Matchup Calculator:** An R Shiny tool for evaluating bullpen matchups.
- **Forecasting Hitter Skills:** Next-season projections for strikeout rate, walk rate, and power, using regression, random forests, and historical backtesting.
- **Capstone:** Research report, executive summary, and presentation.
